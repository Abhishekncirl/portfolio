# Abhishek Yadav — Business Analyst Portfolio

Personal portfolio site for **Abhishek Yadav** — Business Analyst based in Dublin, Ireland.

**Live:** https://abhishekncirl.github.io/portfolio/

## Stack
- Static HTML / CSS / JavaScript
- No build step, no dependencies
- Hosted on GitHub Pages

## Structure
```
.
├── index.html      # Single-page site
├── styles.css      # Theme + layout
├── script.js       # Nav toggle, reveal-on-scroll, year
├── assets/         # CV PDF, images
└── README.md
```

## Local preview
Open `index.html` directly in a browser, or serve with any static server:
```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy
Push to `main` — GitHub Pages builds from the repo root.
