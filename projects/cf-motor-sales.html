Overview

Duration: August 2026 to October 2026

CF Motor Sales is a complete, custom-built web platform for a car dealership that imports UK and Japanese vehicles, sells car parts, and offers vehicle finance. The site gives customers a modern way to browse stock, shop for parts, apply for finance, and leave reviews. It also gives the owner a full admin system to manage every piece of content themselves, with no ongoing developer involvement.

The project was delivered end to end: brand-led design, front-end development, a secure cloud backend, an admin CMS, automated deployment, a custom domain, and go-live. After launch, it was extended with new modules for car parts, finance, and customer reviews.

The challenge

The dealership needed more than a brochure site. Imports and parts change constantly, so the owner had to be able to add, edit, and remove listings instantly without touching code. Buyers needed to browse stock and parts on their phones, calculate finance, and get in touch quickly over WhatsApp. All of it had to run on a tight, predictable hosting budget. The solution had to be fast, fully responsive, self-manageable, and cheap to run.

Key features

Vehicle showroom

Searchable, filterable stock listings with image galleries, zoom, and detailed spec pages.

Car parts shop

E-commerce-style parts catalogue with category and price filters, plus Amazon-style product detail pages.

Finance application

Multi-step application with a live Hire-Purchase and APR calculator, plus admin-editable rates and fees.

Customer reviews

Star-rated reviews customers submit themselves, published only after admin moderation.

WhatsApp enquiries

One-tap enquiries that pre-fill the vehicle or part, price, and a link straight into WhatsApp.

Admin CMS

Full control of vehicles, parts, photos, finance enquiries, reviews, and site settings.

Document export

Finance enquiries export to Word and PDF and email to the finance team, with the selected car included.

Responsive & SEO-ready

Mobile, tablet, and desktop layouts, SEO meta and social-share previews, and HTTPS on a custom domain.

Project flow

  1. 1

    Discovery & requirements

    Defined the dealership's goals, content types (vehicles, parts, finance, reviews), and the must-have ability for the owner to manage everything without code.

  2. 2

    Design & branding

    Built a custom, brand-led UI from the client's logo and colours. A responsive design system in Tailwind covered every page and the admin area.

  3. 3

    Front-end build

    Developed the site in React and TypeScript with client-side routing, code-splitting, image optimisation, and accessibility baked in.

  4. 4

    Backend & data

    Set up Firebase with Firestore database, admin authentication, and image storage, including security rules and caching for fast, cheap reads.

  5. 5

    Feature modules

    Built the showroom, the parts shop, the finance application with its calculator, and the reviews system. Each has its own public pages and admin CRUD.

  6. 6

    Admin CMS

    Created a secure, mobile-friendly dashboard so the owner can manage listings, moderate reviews, handle enquiries, upload photos, and edit finance figures. Storage is auto-cleaned on delete.

  7. 7

    Testing

    Validated finance maths, forms, and flows end-to-end as both customer and admin, plus responsive testing across devices.

  8. 8

    Deployment & domain

    Automated build-and-deploy pipeline (CI/CD) to GitHub Pages, connected the custom domain cfmotorsales.com with DNS and HTTPS.

  9. 9

    Launch & iteration

    Went live, then shipped further modules (car parts, finance options, customer reviews) and refinements based on client feedback.

Architecture at a glance

A fast single-page React app is served as static files from a global CDN. It talks directly to Firebase for live data and image storage, with a lightweight caching layer in front of reads. Admin actions are protected by Firebase Authentication and enforced server-side by Firestore security rules, so the public can only read approved and available content and submit forms.

Client: React SPA (static, CDN) Data: Firestore Auth: Firebase Authentication Media: Firebase Storage Deploy: GitHub Actions → Pages

Outcome

  • Live in production on the client's own domain, fully responsive across phone, tablet, and desktop.
  • Zero ongoing content cost. The owner manages all vehicles, parts, photos, finance settings, and reviews through the admin CMS.
  • Two platforms in one. A vehicle showroom and a car-parts shop, plus finance and reviews modules.
  • Runs lean. Static hosting on a global CDN with a serverless Firebase backend keeps running costs minimal.
  • Built to grow. New sections were added after launch without re-architecting the site.
